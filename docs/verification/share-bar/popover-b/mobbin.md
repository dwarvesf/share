# Mobbin comparison, popover B

Searched through the Mobbin MCP on 2026-11-15 (web screens; no Mac menu bar popover set exists, so these are the nearest patterns). Each screen of the build was compared with the reference that matches its job. Where the build differs, the reason is stated.

| Build screen | Reference | What the reference does | Build | Verdict |
|---|---|---|---|---|
| drop overlay (`drop-*.png`) | [Wix upload media](https://mobbin.com/screens/7340f4d8-f0cd-42e7-b784-4e6161d6aeb3), [Plane upload image](https://mobbin.com/screens/63d419df-49f0-4013-b2cd-1b4adb22463c), [incident.io add images](https://mobbin.com/screens/afb31004-be2b-4c4e-9ea0-5c29219f0b45) | A thin dashed border around the zone, one plain sentence ("Drag & drop files here"), a muted second line. | A 2 pt dashed accent border, one bold sentence that names the host, one muted line that names the storage. | Same pattern, stronger border because the overlay appears only during a drag and must be seen at once.
